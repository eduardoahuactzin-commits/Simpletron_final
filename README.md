
# Proyecto Simpletron

## Descripción
Este proyecto consiste en desarrollar un simulador Simpletron y un compilador para un lenguaje de programación sencillo llamado Simple.

## Objetivo
Comprender el funcionamiento de un procesador básico, ejecutar instrucciones en lenguaje máquina y traducir programas escritos en Simple a instrucciones SML.
